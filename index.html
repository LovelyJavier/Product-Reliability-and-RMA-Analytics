Product Reliability and RMA Analytics

1. Project Overview

Analyze RMA data to assess product reliability, customer return patterns, manufacturing quality performance, and identify improvement opportunities through data analytics.

Tools Used: Excel, Power Query, Pivot Tables, Data Visualization

2. Dashboard Overview

3. Business Questions

  • What is the overall Return Material Authorization (RMA) rate?
  • Which manufacturing cohorts have the highest RMA occurrence?
  • When do RMA cases occur frequently by month and week?
  • How does the cumulative RMA rate change as product age increases?
  • Which manufacturing period and components contribute most to RMA?
  • How does cumulative RMA vary across manufacturing cohorts?
  • Which product categories contribute the most failures?
  • What are the most common failure modes reported by customers?

4. Data Preparation

Step Description
Data Sources Combined RMA, Product, Manufacturing, Shipment, and Customer datasets into a single dataset for analysis.
Data Cleaning Used Power Query transformations to remove duplicates, standardize formats, and clean inconsistent values.
Text Extraction Extracted relevant information from Notes field including failure descriptions and product details.
Data Standardization Mapped failure descriptions into standardized failure modes, categories, and issue classifications.
Data Integration Merged manufacturing, shipment, and product information using Power Query relationships.
Output Created a clean analytical dataset used for dashboard development and reliability analysis.
